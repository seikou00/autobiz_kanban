# Code 阶段批次内迭代修改 - 流程图

## 1. 正常迭代流程

```
┌─────────────────────────────────────────────────────────────┐
│                     批次内迭代修改流程                         │
└─────────────────────────────────────────────────────────────┘

用户开始
   │
   ▼
┌──────────────┐
│ start T1     │ ───► 检查任务状态
└──────────────┘
   │
   ├─ status = "todo" ────────────► ✅ 允许启动
   │
   ├─ status = "in_progress" ────► ✅ 允许（恢复）
   │
   └─ status = "implemented" ────► 检查 batchCompile.status
                                      │
                                      ├─ "pending" ──► ✅ 允许启动
                                      │                  │
                                      │                  ▼
                                      │              Task.status = "in_progress"
                                      │              创建新 run-xxx
                                      │                  │
                                      │                  ▼
                                      │              用户修改代码
                                      │                  │
                                      │                  ▼
                                      │              finish-implementation
                                      │                  │
                                      │                  ▼
                                      │              记录新 evidence
                                      │              Task.status = "implemented"
                                      │              Task.revision += 1
                                      │
                                      ├─ "passed" ───► ❌ 拒绝
                                      │                 (task_locked_after_compile)
                                      │
                                      ├─ "failed" ───► ❌ 拒绝
                                      │                 (需要 start-batch-compile-repair)
                                      │
                                      └─ "repairing" ► ❌ 拒绝
                                                        (修复进行中)
```

## 2. Evidence 追踪机制

```
┌─────────────────────────────────────────────────────────────┐
│                     Evidence 版本追踪                          │
└─────────────────────────────────────────────────────────────┘

第一次实现
   │
   ▼
┌────────────────────────────────────────────┐
│ Task1                                      │
│ ├─ implementationEvidenceIds: ["E1"]      │
│ ├─ latestImplementationEvidenceId: "E1"   │
│ └─ implementationRevision: 1              │
└────────────────────────────────────────────┘
   │
   │ 用户继续对话："改一下这个函数"
   │
   ▼
第二次实现
   │
   ▼
┌────────────────────────────────────────────┐
│ Task1                                      │
│ ├─ implementationEvidenceIds: ["E1","E2"] │
│ ├─ latestImplementationEvidenceId: "E2"   │
│ └─ implementationRevision: 2              │
└────────────────────────────────────────────┘
   │
   │ 用户再次修改
   │
   ▼
第三次实现
   │
   ▼
┌────────────────────────────────────────────────┐
│ Task1                                          │
│ ├─ implementationEvidenceIds: ["E1","E2","E3"]│
│ ├─ latestImplementationEvidenceId: "E3"       │
│ └─ implementationRevision: 3                  │
└────────────────────────────────────────────────┘
   │
   │ 批次编译使用 E3 作为基线
   │
   ▼
batch-compile
   │
   ▼
Task1.status = "done" (锁定)
```

## 3. 状态机

```
┌─────────────────────────────────────────────────────────────┐
│                     Task 状态机                                │
└─────────────────────────────────────────────────────────────┘

           start
    ┌─────────────┐
    │    todo     │
    └─────────────┘
           │
           │ start (首次)
           ▼
    ┌─────────────┐
    │ in_progress │◄─────┐
    └─────────────┘      │
           │             │
           │ finish      │ start (重新启动)
           │             │ [仅当 batchCompile.status="pending"]
           ▼             │
    ┌─────────────┐      │
    │ implemented │──────┘
    └─────────────┘
           │
           │ batch-compile (passed)
           ▼
    ┌─────────────┐
    │    done     │ (终态，不可逆)
    └─────────────┘
```

## 4. 批次编译状态保护

```
┌─────────────────────────────────────────────────────────────┐
│                  Batch Compile 状态保护                        │
└─────────────────────────────────────────────────────────────┘

batchCompile.status
   │
   ├─ "pending" ────► 允许重新启动任务
   │                  │
   │                  └─► start T1 ✅
   │
   ├─ "passed" ─────► 批次已完成，代码锁定
   │                  │
   │                  └─► start T1 ❌
   │                      错误: task_locked_after_compile
   │
   ├─ "failed" ─────► 编译失败，需要受控修复
   │                  │
   │                  └─► start T1 ❌
   │                      错误: batch_compile_repair_required
   │                      正确方式: start-batch-compile-repair
   │
   └─ "repairing" ──► 修复进行中，禁止其他操作
                      │
                      └─► start T1 ❌
                          错误: batch_compile_repair_in_progress
```

## 6. 决策树

```
开始重新启动任务？
   │
   ▼
任务状态 = "implemented"？
   │
   ├─ No ──► ✅ 正常启动流程
   │
   └─ Yes ─► 是 compile repair？
                │
                ├─ Yes ─► ✅ 允许（修复流程）
                │
                └─ No ──► batchCompile.status？
                            │
                            ├─ "pending" ──► ✅ 允许重新启动
                            │
                            ├─ "passed" ───► ❌ 拒绝
                            │                 (批次已完成)
                            │
                            ├─ "failed" ───► ❌ 拒绝
                            │                 (需要走修复流程)
                            │
                            └─ "repairing" ► ❌ 拒绝
                                              (修复进行中)
```

## 图例说明

- `✅` = 允许的操作
- `❌` = 拒绝的操作
- `───►` = 单向流转
- `◄───►` = 双向通信
- `│` = 决策分支
