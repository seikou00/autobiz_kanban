## 前端需求完整性检查清单（聚焦页面元素与操作交互）

> 说明：本清单不涉及UI视觉风格、页面布局，仅检查页面元素与操作交互需求是否说明清楚。

---

### 一、页面元素完整性

#### 1.1 静态内容检查
- [ ] **说明文字**：是否有辅助说明、提示文案？内容是什么？
- [ ] **标签/占位符**：输入框标签、占位符文字是否确定？
- [ ] **其他静态文本**：如有其他固定显示的文字内容，是否明确？

#### 1.2 动态内容检查
- [ ] **数据来源**：动态展示的内容（如列表数据、统计数字、状态文字等）来源是否清晰？

#### 1.3 表单控件检查
- [ ] **输入框**：是否有文本输入？是否需要字数限制？
- [ ] **下拉选择**：是否有下拉选择？选项是什么？
- [ ] **单选按钮**：是否有单选？选项有哪些？
- [ ] **开关**：是否有开关控件？开启/关闭状态的意义？
- [ ] **日期选择器**：是否有日期选择？格式要求？
- [ ] **其他控件**：如有其他特殊控件，是否说明？

#### 1.4 条件渲染/隐藏元素检查
- [ ] **条件渲染**：是否有根据条件显示/隐藏的元素？
- [ ] **触发条件**：条件渲染的触发条件是否定义清楚？
  - 条件类型：用户角色 / 数据状态 / 权限 / 其他
- [ ] **显示逻辑**：显示时内容是什么？隐藏时如何处理？

#### 1.5 只读/禁用状态检查
- [ ] **只读元素**：是否有只读显示的内容？对应什么场景？
- [ ] **禁用元素**：是否有禁用状态的按钮/输入框？触发条件是什么？
- [ ] **状态说明**：只读/禁用时的样式和行为是否说明？

---

### 二、用户交互逻辑

#### 2.1 可交互元素行为定义
- [ ] **按钮**：每个按钮点击后的行为是否明确？
  - 例如："点击'提交'按钮后触发校验并发送请求"
- [ ] **链接/跳转**：点击链接后跳转到哪里？
- [ ] **表单项**：输入/选择后数据如何处理？是否立即保存？
- [ ] **其他交互**：如有拖拽、滑动等特殊交互，是否说明？

#### 2.2 危险操作二次确认检查
- [ ] **删除操作**：删除数据是否需要弹窗确认？
- [ ] **危险操作**：是否有其他需要二次确认的操作？
- [ ] **确认文案**：二次确认的弹窗文案是什么？



---

### 三、常见待补充问题（供需求澄清使用）

| 场景 | 待确认问题 |
|:---|:---|
| 列表展示 | 列表默认按什么排序？能切换排序吗？ |
| 空状态 | 没数据时是空白还是显示提示？提示内容是什么？ |
| 权限控制 | 用户没权限时，是隐藏按钮还是禁用按钮？ |
| 二次确认 | 这个操作需要二次确认吗？确认弹窗文案是什么？ |
| 状态变化 | 这个元素什么情况下会变只读/禁用？ |
